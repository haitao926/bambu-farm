# 校园拓竹打印机集群管理系统 - 需求说明书 (Requirement Specification)

## 1. 项目背景
在学校场景下，需要集中管理 20 台拓竹（Bambu Lab）3D 打印机。旨在解决打印机被随意占用、状态难以监控、打印文件管理混乱等问题，建立一个安全、高效、自动化的私有云打印服务平台。

## 2. 核心业务流程
系统需实现以下闭环流程：
1.  **学生提交**：学生登录平台，上传切片文件 (.3mf)，填写打印需求。
2.  **老师审核**：老师查看队列，预览模型（3D渲染或缩略图），一键批准或驳回。
3.  **自动分发**：系统自动检测空闲且状态正常的打印机，将文件分发至打印机 SD 卡并启动打印。
4.  **状态监控**：实时展示打印进度、剩余时间及摄像头画面。
5.  **完成闭环**：打印完成后自动通知学生领取，学生确认收货后释放机位。

## 3. 功能需求

### 3.1 学生端 (Web)
*   **用户认证**：简单的账号登录（对接学校系统或独立账号）。
*   **任务提交**：
    *   上传 `.3mf` (G-code) 文件（限制文件格式）。
    *   选择耗材类型（PLA/PETG等，用于匹配机器）。
    *   填写备注信息。
*   **我的任务**：
    *   查看任务状态（待审核、排队中、打印中、已完成、已驳回）。
    *   **实时监控**：在打印中状态下，查看分配机位的实时视频流、百分比进度、剩余时间。
    *   **领取确认**：收到通知后，在系统点击“确认领取”以完成任务。

### 3.2 教师/管理端 (Web)
*   **全局仪表盘**：
    *   20 台机器的实时状态概览（空闲、打印中、故障、离线）。
    *   腔体温度、喷头温度等关键指标监控。
*   **任务审核**：
    *   查看待审核队列。
    *   **在线预览**：解析 .3mf 文件预览模型几何形状（Three.js）或切片缩略图。
    *   操作：批准（进入打印队列）、驳回（填写理由）。
*   **设备管理**：
    *   手动控制（紧急停止、暂停）。
    *   绑定/解绑设备（IP与物理编号对应）。

### 3.3 系统核心逻辑 (Scheduler)
*   **队列管理**：维护 FIFO（先进先出）打印队列，支持优先级调整（可选）。
*   **智能调度**：
    *   轮询 20 台机器状态 (MQTT)。
    *   匹配条件：`gcode_state: "idle"` (空闲) AND `chamber_temperature` < 安全阈值。
    *   负载均衡：优先分配给空闲时间最长的机器（可选）。
*   **自动化控制**：
    *   **传输**：使用 FTPS (Port 990) 将文件静默上传至目标机器。
    *   **指令**：发送 MQTT `project_file` 指令触发打印。
*   **通知服务**：通过 Webhook (企业微信/钉钉) 或邮件发送状态变更通知。

## 4. 非功能需求
*   **网络环境**：纯局域网部署，打印机与服务器位于独立 VLAN，禁止外网直接访问打印机。
*   **并发性能**：支持 20 路 MQTT 长连接，低延迟状态刷新。
*   **视频流**：20 路 RTSP 转 WebRTC/HLS，保证低延迟且不卡顿。
*   **存储**：支持大容量存储（历史模型归档）。
